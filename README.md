# EnglishSmart Demo

Demostración interactiva de exámenes de inglés para profesores y estudiantes.

## Publicar con GitHub Pages

1. Sube el archivo HTML completo con el nombre `index.html` en la raíz de la rama `main`.
2. Abre **Settings → Pages** en este repositorio.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona **main** y **/(root)** y guarda los cambios.
5. Abre: https://jabs9323.github.io/EnglishSmart_Demo/

El examen contiene recursos de audio integrados; conservar `index.html` completo. Los datos almacenados en `localStorage` permanecen en el navegador de cada usuario y no se sincronizan entre dispositivos.
